# 洞洞板手机收纳架 · 4 槽（拓竹 A1 打印）

对应文件：`pegboard_phone_holder.scad`（参数化源文件）、`pegboard_phone_holder.stl`（打印用）

## 1. 关键尺寸

| 项目 | 数值 | 说明 |
|---|---|---|
| 外形尺寸 | 66 × 88 × 100 mm | 宽 × 深 × 高（不含挂销，含销总深 96） |
| 卡槽数 | 4 | 槽宽 13.5 mm，隔板 2.4 mm |
| 槽内可用深度 | 79 mm | 手机宽度 ≤ 79 完全落入槽内 |
| 槽内可用高度 | 100 mm | 背板高，手机上部露出 |
| 充电过线窗 | 每槽 13.5 × 14 mm 贯通 | 位于槽底靠背侧，数据线从下方穿上来 |
| 挂销数量 | **6 个（3 排 × 2）** | 排高 80 / 48 / 16（排距 32）；列距 16 |
| 挂销形状 | Ø5.5 销身 + **Ø6.0 卡环** + 球头顶端 | 总长 8，卡环中心距板面 3.7 |
| 最小壁厚 | 2.4 mm | 无薄壁 |
| 实体体积 | 123.9 cm³ | 水密单实体；床面接触 42.6 cm²；超 45° 悬垂仅 1.5% |

> 挂销尺寸照抄参考件「手电钻16mm」：销身 Ø5.5、卡环 Ø6.0、总长 8、卡环距板面 3.7、球头收尾。
> 卡环直径 ≈ 孔径，压过孔时挤压变形，产生止退力——这就是它替代"弯钩"的地方（钩头过不了 Ø6 孔，而且和另外 4 个定位销直插冲突）。

## 2. 打印参数（Bambu Studio / A1）

| 项目 | 设定 |
|---|---|
| 喷嘴 / 层高 | 0.4 mm / 0.20 mm（首层 0.25） |
| 墙层数 | 4（外壁 0.42 线宽） |
| 顶/底实心层 | 5 / 4 |
| 填充 | 15% Gyroid（或 20% 网格） |
| 支撑 | **不需要**（全部 45° 自支撑） |
| 摆放 | 直接导入，**不要旋转**（底面已贴床） |
| 附着 | 底面接触 42.6 cm²，一般不用 brim |
| 预计耗材 / 时间 | 约 80–95 g / 4–5 h（0.2 层高） |
| 材料建议 | PLA 足够；PETG 更韧，收缩调 0.3% |

打印方向：站立打印，底面 66 × 76 贴床，背板在后侧竖直生长。6 个挂销是水平圆柱，横向伸出，靠自身层间支撑（和参考件一样）。

## 3. 安装

1. 在洞洞板上找 **3 排 × 2 列**的孔：每排相邻两孔（16 mm），排间隔一个孔（32 mm）。
2. 对准后**整块直推压入**，感觉到卡环过孔即可。别用锤子，手掌推就行。
3. 拆卸：握住两侧往外平拉。
4. 数据线从架子下方穿进槽底过线窗，插头落在手机底边位置，再把手机立进槽里。

注意事项：

- 卡环 Ø6.0 是按 6 mm 孔、5 mm 板做的。太紧把 `rib_d` 改 5.8 重导；太松改 6.2。
- 板厚 3 mm 以下时卡环会落在板背面之外，变成普通销（仍能挂，但没有止退）。
- 手机宽度超过 79 mm（折叠屏展开等）时，底边会搭在前挡唇上、略微后仰，仍然能放。

## 4. 想改尺寸？改 `.scad` 顶部这几个数

| 需求 | 参数 | 建议值 |
|---|---|---|
| 减一个槽 | `slots` | 4 → 3（外形自动变窄） |
| 放带厚壳的手机 | `slot_w` | 13.5 → 15 |
| 放平板 | `slot_w` / `depth` / `back_h` | 18 / 180 / 150 |
| 孔距不是 16 mm | `pitch` | 按实测中心距填 |
| 卡环偏紧 | `rib_d` | 6.0 → 5.8 |
| 不要充电窗 | `charge_on` | true → false |
| 过线窗要深一点 | `charge_d` | 14 → 18 |
| 挂销少两排 | `peg_rows` | [80, 48, 16] → [60, 28] |

改完在 OpenSCAD 里 `F5` 预览、`F6` 渲染、`Export → STL` 即可。参数都有注释，单位 mm。

## 5. 已知取舍

- 槽深按常见手机宽度（iPhone 71.6 / Pro Max 76.7 / Pixel 76.5）取 88，整件离墙 88 mm。要更薄可以改 `depth`，代价是手机底部外露。
- 3 排挂销中只有中间一排处在最受力位置，上下两排主要抗翻转、抗拔出。
- 过线窗把槽底靠背 14 mm 挖空，手机底边靠前约 60 mm 支撑；不插线时底边靠背那一小段是悬空的，插着线时正好由插头垫住。
